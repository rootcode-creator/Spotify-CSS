# Spotify-CSS

A static front-end clone of the Spotify web player experience built with HTML and CSS only. The project recreates a dark, modern music-app layout with a sidebar, library section, content cards, and a bottom music player.

## 🚀 Project intro

Spotify-CSS is a UI-focused recreation of a Spotify-inspired interface. It is designed to showcase how a polished music streaming layout can be built using only HTML and CSS, without any JavaScript-powered playback or backend services.

## ⭐ Key highlights

- Clean Spotify-inspired dark theme
- Sidebar navigation with Home and Search links
- Library section with playlist and podcast prompts
- Content cards for featured music sections
- Bottom music player with controls and volume slider
- Responsive layout adjustments for smaller screens

## 🔧 Features

### UI layout

- Left sidebar with navigation and library area
- Main content area with sticky top navigation
- Sections for recently played, trending content, and featured charts
- Fixed bottom player bar with album info and playback controls

### Styling

- Custom CSS layout and spacing
- Rounded cards and panels
- Hover states for navigation and media controls
- Font Awesome icons and Google Fonts integration

## 🧰 Tech stack

- HTML5
- CSS3
- Font Awesome icons
- Google Fonts (Montserrat)
- Local image assets

## ⚙️ Run locally

1. Clone the repository.
2. Open the project folder.
3. Launch the app by opening the index.html file in your browser.

If you prefer a local server, you can also run:

```bash
python -m http.server 8000
```

Then open:

```txt
http://localhost:8000
```

## 📝 Notes

- This project is a static front-end UI clone.
- It does not include real music streaming, account authentication, or backend functionality.
- All visual assets are stored locally in the assets folder.
